# Beyond My Universe

A one-month courtship journey for Julie, from James Neil Traigo. The entrance password is **JULIE**.

## Add your photo and song

- Replace `assets/julie-us.jpg` with your own JPEG photo. Use the exact filename `julie-us.jpg`. The frame crops the image to fit, so keep both faces near the center.
- Copy your own MP3 into `assets/` and name it `music.mp3`. The player starts after you press **Enter my universe** or the play button. If the file is absent, the player shows a short message and the rest of the journey continues.

## Run in VS Code

1. Extract the ZIP. In VS Code, choose **File → Open Folder** and select `julie-universe`, the folder containing `index.html`.
2. In **Extensions**, install [Live Server by Ritwick Dey](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer).
3. In VS Code’s Explorer, right-click `index.html` and choose **Open with Live Server**. Use the browser tab that opens.
4. Enter **JULIE**, then choose any planet from the star map. The final scene unlocks after all five planets have been visited.

The password is a front-end part of the story. The letters are in `index.html`, the styles are in `css/style.css`, and the interactions and short star messages are in `js/script.js`.
